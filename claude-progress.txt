TECHNICAL DESIGN (KISS APPROACH)

Storage Schema Change:
```python
# Current structure (storage/hash_table.json):
{
    "transaction_ids": ["hash1", "hash2", ...],
    "addresses": {"encrypted_hash": "Category Name"},
    "categories": {"Category Name": 12345.67}
}

# NEW structure (backward compatible):
{
    "transaction_ids": ["hash1", "hash2", ...],
    "addresses": {"encrypted_hash": "Category Name"},
    "categories": {"Category Name": 12345.67},
    "transactions": [  # NEW FIELD
        {
            "date": "2024-01-15",  # ISO format YYYY-MM-DD
            "address_hash": "encrypted_hash",  # Encrypted, same as in addresses
            "amount": 99.99,  # Float
            "category": "Entertainment"  # String
        }
    ]
}
```

Migration Strategy:
- If "transactions" key doesn't exist, create empty list
- New transactions append to list during processing
- Old data: category totals still work (no breaking changes)
- New data: enables pattern detection

Algorithm Pseudocode:

```python
# Subscription Detection
def detect_subscriptions(transactions):
    # Group by address_hash
    grouped = group_by(transactions, 'address_hash')

    subscriptions = []
    for address_hash, txns in grouped.items():
        if len(txns) < 3:
            continue  # Need 3+ occurrences

        # Sort by date
        sorted_txns = sort_by_date(txns)

        # Calculate intervals between consecutive transactions
        intervals = []
        for i in range(1, len(sorted_txns)):
            days = date_diff(sorted_txns[i], sorted_txns[i-1])
            intervals.append(days)

        # Check if intervals are consistent (~monthly: 25-35 days)
        avg_interval = mean(intervals)
        if 25 <= avg_interval <= 35:
            # Check amount consistency (within 10%)
            amounts = [t['amount'] for t in sorted_txns]
            if coefficient_of_variation(amounts) < 0.1:
                subscriptions.append({
                    'address': decrypt(address_hash),
                    'amount': mean(amounts),
                    'frequency': 'monthly',
                    'count': len(txns),
                    'total': sum(amounts),
                    'last_date': sorted_txns[-1]['date']
                })

    return subscriptions

# Spending Trends
def analyze_spending_trends(transactions):
    # Group by category and month
    monthly_spending = {}
    for txn in transactions:
        month = txn['date'][:7]  # YYYY-MM
        category = txn['category']

        if month not in monthly_spending:
            monthly_spending[month] = {}

        if category not in monthly_spending[month]:
            monthly_spending[month][category] = 0.0

        monthly_spending[month][category] += txn['amount']

    return monthly_spending
```

USER FEEDBACK INCORPORATED:

**Approach Simplified (KISS principle):**
Instead of complex subscription detection with strict thresholds:
- Group transactions by merchant (frequent merchant detection)
- Calculate average interval between transactions for each merchant
- Categorize regularity based on interval:
  * Weekly: ~7 days (5-10 day range)
  * Monthly: ~30 days (20-40 day range)
  * Yearly: ~365 days (330-400 day range)
  * Irregular: everything else
- No complex variance checks or strict criteria
- Simple, actionable insights

**Updated Algorithm (Simpler):**
```python
def analyze_merchants(transactions):
    # Group by address_hash
    grouped = group_by(transactions, 'address_hash')

    merchants = []
    for address_hash, txns in grouped.items():
        count = len(txns)
        total = sum(t['amount'] for t in txns)

        # Calculate average interval if 2+ transactions
        regularity = 'single'
        if count >= 2:
            sorted_txns = sort_by_date(txns)
            intervals = [date_diff(sorted_txns[i], sorted_txns[i-1])
                        for i in range(1, len(sorted_txns))]
            avg_interval = mean(intervals)

            # Simple categorization
            if 5 <= avg_interval <= 10:
                regularity = 'weekly'
            elif 20 <= avg_interval <= 40:
                regularity = 'monthly'
            elif 330 <= avg_interval <= 400:
                regularity = 'yearly'
            else:
                regularity = 'irregular'

        merchants.append({
            'address': decrypt(address_hash),
            'count': count,
            'total': total,
            'avg_amount': total / count,
            'regularity': regularity
        })

    return sorted(merchants, key=lambda m: m['total'], reverse=True)
```
